# Muhammad Abdullah — Portfolio Website

A premium, cinematic, responsive web portfolio built for **Muhammad Abdullah**, a multi-skilled Web Developer, Graphic Designer, Video Editor, Social Media Handler, Photographer & Customer Specialist based in Lahore, Pakistan.

---

## Features & Highlights

- **Cinematic Dark Theme Aesthetics**: Dark crimson & ambient glow lighting to match the brand.
- **Hero & Headline Section**: Bold typographic headline, live availability badge, experience stats, and hero background photo.
- **My Work — Portfolio Grid**: A categorized image grid (Web Development, Graphic Design, Video Editing, Social Media, Customer Service, Leadership, Photography) with labels on every item.
- **6-Card Services Grid**: Web Development, Graphic Design, Video Editing, Social Media Handling, Photography, Customer Specialist — each with its own preview image.
- **Client Stories & Reviews Carousel**: Testimonial slider with star ratings.
- **Get In Touch & Contact Form**: Functional contact section integrated with EmailJS for direct inquiry handling, plus a "Request Number" link that opens a pre-filled email instead of exposing a phone number publicly.

## Technologies Used

- **HTML5**: Semantic markup.
- **CSS3**: Custom CSS variables, flexbox, CSS Grid, glassmorphism, `@keyframes` animations.
- **JavaScript (ES6+)**: Vanilla JS for navigation, carousel slider, counter animations.
- **FontAwesome 6.5.2**: Scalable vector icons.
- **Google Fonts**: *Poppins* font family.
- **EmailJS SDK v4**: Contact form submission handling (connected to Abdullah's own EmailJS account).

## Deployment — GitHub Pages

1. Push this folder's contents to a GitHub repository (root or a `docs/` folder).
2. Go to your repo's **Settings → Pages**.
3. Under "Build and deployment", choose **Deploy from a branch**, select your branch (e.g. `main`) and the root folder.
4. Save — GitHub will publish your site at `https://<your-username>.github.io/<repo-name>/`.
5. The `.nojekyll` file is already included so GitHub Pages serves the site as-is without Jekyll processing.
